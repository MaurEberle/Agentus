# الإعدادات

الترس في الشريط العلوي. الأقسام يسارًا: المظهر، بيانات الاعتماد، وقت التشغيل، دردشة المساعدة، خوادم MCP، البيانات، حول. حقول غير محفوظة عند التبديل: حوار البقاء / التجاهل.

## المظهر

فاتح أو داكن أو النظام — لكل التطبيق بما فيه الشريط. **اللغة** قائمة منسدلة بعلم: Deutsch, English, Español, Français, Türkçe, Português, 中文, 日本語, العربية. الاسم بين القوسين ترجمة بلغة الواجهة الحالية.

مفتاح **زر المساعدة**: يظهر أو يخفي الفقاعة أسفل اليمين. **إعداد** روبوت الدردشة يبقى تحت **دردشة المساعدة** حتى إن أُخفيت الفقاعة.

## بيانات الاعتماد

أسرار مسماة لنماذج السحابة وبحث الويب وبعض وصفات MCP. الإنشاء: الاسم والنوع والسر **مرة**. بعدها **القناع** فقط. التحرير قد يستبدل السر (فارغ = بلا تغيير).

الأنواع منها: xAI، OpenAI، Claude، Gemini، متوافق مع OpenAI، بحث الويب، GitHub، Azure، GitLab، Slack، Notion، Atlassian، Linear، Postgres، رمز.

**الحذف** مقفل ما دام ملف المساعدة أو شبكة (LLM/أداة) أو خادم MCP يستخدم الاعتماد. أزل الربط أولًا.

## وقت التشغيل

**عنوان أساس Ollama** (غالبًا العنوان المحلي لـ Ollama). **فحص الاتصال** و**قائمة النماذج** يمرّان عبر التطبيق. تنقسم القائمة إلى **نماذج عادية** و**نماذج تضمين**. يُعد النموذج تضمينًا إذا احتوى اسمه على `embed`. المجموعة الفارغة تعرض **لا شيء**.

إذا كان العنوان محليًا وOllama مثبتًا لكنه متوقف، يشغّل التطبيق الخدمة عند فتح النافذة ولا يوقفها. بلا Ollama متاح تتوقف عقد LLM المحلية والمساعدة الافتراضية. تثبّت النماذج بـ Ollama أو عند الإعداد؛ التطبيق **لا** يسحب بصمت أثناء التشغيل. عنوان أساس متوافق مع OpenAI لم يعد يُعرض هنا.

## دردشة المساعدة

الموضع الوحيد لودجة المساعدة. ناقصة بلا مزوّد دردشة ونموذج دردشة.

- مزوّد الدردشة ونموذجها (الافتراضي Ollama / `llama3.2:1b`)
- اعتماد سحابة اختياري
- **مزوّد التضمين ونموذجه** (الافتراضي Ollama / `nomic-embed-text`) — **ليس** نموذج الدردشة
- نموذج اقتصادي اختياري (احتياطي، الافتراضي نفس الدردشة الصغيرة)
- بحث الويب تشغيل/إيقاف مع اعتماد البحث؛ بلا اعتماد تبقى الدردشة مُعدّة والبحث متوقف
- فحص الاتصال، مسح السجل، **إعادة بناء الفهرس**، إظهار الترحيب مجددًا

بعد تغيير نموذج التضمين أو ملفات جديدة في مجموعة المساعدة: **إعادة بناء الفهرس**. يستمر العمل إذا غادرت الإعدادات. النقرة الثانية لا تبدأ فهرسًا ثانيًا. المجموعة مجلد وثائق المساعدة في مجلد البيانات، وليست معرفة الشبكة. الأدلة الجديدة المرفقة لا تستبدل بنفسها الملفات الموجودة هناك.

تجيب المساعدة بلغة الواجهة. إن لم يستطع النموذج تلك اللغة أجاب بالإنجليزية. لا تذكر عناوين وثائق الأدلة. بحث الويب وحده يعرض المصادر، كعنوان ورابط. كتل التفكير الداخلية للنموذج لا تظهر. المساعدة **لا** تستخدم خوادم MCP ولا معرفة الرسوم.

## خوادم MCP

قوالب (**وصفات**) لأدوات خارجية: GitHub، نظام الملفات، Git، Playwright، Postgres، Slack، Notion، صيغ Office وغيرها. الوصفات ليست برامج مرفقة. كثير منها يحتاج Node/`npx` أو Docker أو `uvx` على الحاسوب مع اعتماد.

الافتراضي: الخادم **غير نشط**. لا يبدأ التطبيق عمليات MCP عند الفتح، بل عندما يحتاج تشغيل إلى عقدة أداة MCP متصلة.

أنشئ من وصفة (اعتماد، مسار جذر اختياري) أو **خادمًا خاصًا** (أمر، وسائط أو URL). استخدم أوامر مجهولة إن وثقت بها فقط. الفحص يتحقق من الوصول؛ «وقت التشغيل ناقص» إن غاب Node/Docker/`uvx`.

Office يجمع PDF وصيغ Office؛ فعّل الإعدادات الفردية فقط إن احتجتها فعلًا.

الحذف يزيل إعداد الخادم لا Ollama ولا بيانات الاعتماد.

## البيانات

يعرض **مجلد البيانات** وحالة المخازن: الإعدادات، المساعدة، مساحة العمل، السجل — بلا عرض SQL وبلا أسرار.

**غيّر** المجلد فقط إن لم تبدأ شبكة أو تعمل أو تتوقف. جذور الأقراص أو النظام غير صالحة. اختياري نسخ المحتوى إلى المجلد الجديد؛ القديم يبقى.

**محمول** أو مجلد مفروض من الخارج: المسار **للقراءة فقط**.

**احتفاظ السجل:** 30 / 90 / 365 يومًا أو بلا حد (الافتراضي 90). يمكن لصفحة السجل تنظيف القيود القديمة وفق ذلك.

## حول

إصدارا الواجهة وواجهة البرمجة، حالة Ollama التقريبية، وهل المخازن متاحة. بلا أسرار ولا مسارات داخلية باسم مستخدم على سطح تشاركه.
