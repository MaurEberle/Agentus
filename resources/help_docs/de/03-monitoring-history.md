# Monitoring und Historie

## Live (Monitoring)

Während eines Laufs: Mini-Graph mit Status, Log (neueste oben), Ressourcen, optional Netz-Chat. Start/Stopp bleiben im **Header**.

## Archiv (Historie)

Abgeschlossene Läufe, Filter, Statistik. Das ist **kein** zweites Dashboard und **kein** Live-Tail. `cancelled` ist nicht `failed`. Ein noch laufender Eintrag ist nur ein Link zum Monitoring.

Logs und Chat-Transkripte maskieren Secrets (`Bearer`, `sk-…`).
