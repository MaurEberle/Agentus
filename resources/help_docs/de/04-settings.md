# Einstellungen

## Zugänge

Anlegen, umbenennen, löschen. Listen zeigen nur **Maske**, nie das Secret. Löschen ist gesperrt, wenn Hilfe, ein Netz oder MCP den Zugang nutzen.

## Datenordner

Wechsel nur wenn kein Lauf aktiv ist. Laufwerkswurzeln sind ungültig. Portable-Modus ist read-only für den Pfad.

## Hilfe-Profil

Hilfe-Modell und **Embeddings** sind getrennt. Embeddings (Default `nomic-embed-text`) sind nicht das Chat-Modell. Nach Korpus-Änderung: **Index neu** in der Hilfe-Sektion.

## MCP

Rezepte sind Vorlagen, keine Binaries. Server standardmäßig aus. Die App startet MCP-Prozesse nicht beim Öffnen — erst wenn ein Lauf verbundene Server braucht.
