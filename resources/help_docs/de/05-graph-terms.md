# Begriffe

**Graph** — gespeichertes Netz aus Knoten und Kanten.

**Run** — ein Ausführungslauf. Nur einer gleichzeitig.

**Credential** — Zugangsschlüssel im Tresor, in Knoten nur als ID.

**MCP** — Model Context Protocol: externe Tools (GitHub, Dateisystem, …) als Knoten `kind: mcp`.

**Hilfe-RAG** — Dokumente im Ordner `agentus_network_rag_documents` für den Hilfe-FAB.

**Netz-Wissen** — Knowledge-Knoten mit eigenem Ordner **unter** dem Datenverzeichnis; nicht der Hilfe-Korpus.
