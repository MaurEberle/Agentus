# 监控与历史

**监控** = 现在，一次运行。**历史** = 归档与统计。历史**不是**第二个仪表板，也**不是**实时日志。启动和停止仍在**标题栏**。

## 实时与归档

| | 监控 | 历史 |
|---|------------|----------|
| 何时 | 服务启动、运行或停止 | 运行结束后（运行中也可链接） |
| 图 | 小图，只读，节点状态 | 已保存快照，无实时更新 |
| 日志 | 流式，最新在上，可暂停 | 固定行，可筛选 |
| 聊天 | 运行聊天，仅在运行期间 | 已保存转录，不能继续写 |

仍在运行的历史条目只是跳转到监控（「查看实时」）。

## 无运行时的监控

没有活动运行时，页面会显示**上次保存的运行**供查看（图、活动、日志、聊天）。提示会说明当前不是实时的。只有从未保存过运行时，页面才完全空白：**无运行**，以及活动网络或快速选择为空的提示。断开 / 错误 / 正在启动 / 正在停止有各自文案。知识正在索引时，启动提示会换成该节点的名称。在连接建立前，上次的值可能变灰。

## 运行期间

头部：运行 ID、开始时间、时长、大致步骤、活动 LLM（本地 vs 云）。

**网络（只读）：** 同一张图，节点颜色按状态（空闲、等待、运行中、完成、错误）。点击节点会筛选日志/活动并打开详情（角色、状态、等待 LLM/工具/输入/索引、最后消息、token）。不能编辑，没有第二个编辑器。

如果智能体挂了知识，启动时在索引期间就会显示这次运行：知识节点以等待原因**索引**运行，日志会写出读取和嵌入，标题栏和仪表板显示同一个名称。已经是最新的索引会被跳过，只记为当前。

**活动：** 当前节点、「步骤 x / y」进度、输入/输出 token、可选上下文窗口。

**主机资源：** **本机** CPU、内存、GPU/显存，不只是应用。没有本地 GPU（云运行时常见）会提示，不是错误。

## 网络聊天（监控）

**聊天**标签：运行中图的对话。仅在运行期间可用。没有编排器时，聊天等待第一行并把它交给链。有编排器时你只和它说话。运行只在追问时等待。智能体正文和内部指令不会出现在这里。

这**不是**帮助气泡。历史和工具属于该网络。

## 日志（监控）

**日志**标签：带级别（调试、信息、警告、错误）、节点、时间的行。最新在上。暂停停止跟随；「跳到最新」再回到末尾。筛选：搜索、起始级别、某个节点、仅错误。导出可见行。

负载和消息会**掩盖**密钥（例如 `Bearer`、密钥前缀）。不要未过滤地转发。

## 历史

功能区：刷新、删除所选运行、导出日志、按保留期清理旧条目（见设置 → 数据，默认 90 天）。

**一个筛选器**控制全部：时间范围（今天、7/30 天、从–到）、网络、模型、搜索（运行 ID、网络、错误）。KPI、「按日运行」图表、常见错误、历史 / 按模型 / 按网络标签和列表共用该筛选。

## 运行结果

| 结果 | 含义 |
|----------|-----------|
| 运行中 | 仍活动 — 历史中仅作为链接 |
| 成功 | 正常结束 |
| 失败 | 步骤或服务失败 |
| 已取消 | 标题栏停止、关闭窗口或应用结束（崩溃后下次启动也会如此） |
| 超时 | 超过时限 |

**已取消不是错误。** 超时和取消在 KPI 中分开计数（「失败」脚注）。

## 运行详情

右侧或独立视图：元数据、小图、**日志**、**步骤**、**聊天**标签。步骤：节点、角色、状态、错误。聊天：转录，只读。可导出单条日志。

删除历史条目不会改变已保存的网络。
