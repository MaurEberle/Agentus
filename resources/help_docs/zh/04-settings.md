# 设置

标题栏中的齿轮。左侧分区：外观、凭据、运行时、帮助聊天、MCP 服务器、数据、关于。切换分区时未保存字段：留下 / 放弃对话框。

## 外观

浅色、深色或系统 — 对整个应用（含标题栏）生效。**语言**是带旗帜的下拉框：Deutsch, English, Español, Français, Türkçe, Português, 中文, 日本語, العربية。括号中的名称是当前界面语言的翻译。

**帮助按钮**开关：显示或隐藏右下角气泡。即使隐藏气泡，聊天机器人的**配置**仍在**帮助聊天**中。

## 凭据

用于云模型、网页搜索和部分 MCP 配方的命名密钥。创建：名称、类型、密钥**一次**。之后只显示**掩码**。编辑可替换密钥（留空 = 不变）。

类型包括：xAI、OpenAI、Claude、Gemini、OpenAI 兼容、网页搜索、GitHub、Azure、GitLab、Slack、Notion、Atlassian、Linear、Postgres、令牌。

只要帮助配置、某个网络（LLM/工具）或 MCP 服务器仍在使用该凭据，**删除**就被锁定。请先取消关联。

## 运行时

**Ollama 基础 URL**（通常是 Ollama 的本地地址）。**检查连接**和**模型列表**走应用。列表分成**普通模型**和**嵌入模型**。名称里含有 `embed` 的算嵌入模型。空的一组显示**无**。

地址是本机、Ollama 已安装但没在运行时，应用会在打开窗口时启动服务，并且不会停止它。无法访问 Ollama 时，本地 LLM 节点和默认帮助会卡住。你用 Ollama 或安装程序安装模型；应用在运行时**不会**静默拉取。这里不再提供 OpenAI 兼容基础 URL。

## 帮助聊天

帮助组件的唯一配置处。没有聊天提供方和模型即为不完整。

- 聊天提供方和模型（默认 Ollama / `llama3.2:1b`）
- 可选云凭据
- **嵌入提供方和模型**（默认 Ollama / `nomic-embed-text`）— **不是**聊天模型
- 可选节省模型（备用，默认同一个小聊天模型）
- 网页搜索开/关加搜索凭据；没有凭据时聊天仍可配置，搜索关闭
- 检查连接、清除历史、**重建索引**、再次显示引导

更换嵌入模型或向帮助语料添加文件后：**重建索引**。离开设置后这项工作仍会继续。再点一次不会开始第二个索引。语料是数据文件夹中的帮助文档文件夹，不是网络知识。随应用带来的新指南不会自动覆盖已经在那里的文件。

帮助按界面语言回答。模型用不了该语言时，用英语回答。它不会列出指南的文档标题。只有网页搜索会给出来源，即标题和地址。模型的内部思考块不会显示。帮助**不**使用 MCP 服务器，也**不**使用图的知识。

## MCP 服务器

外部工具的模板（**配方**）：GitHub、文件系统、Git、Playwright、Postgres、Slack、Notion、Office 格式等。配方不是随附程序。很多需要本机上的 Node/`npx`、Docker 或 `uvx`，外加凭据。

默认：服务器**未启用**。应用不会在打开时启动 MCP 进程，而是在运行需要已连接的 MCP 工具节点时启动。

从配方创建（凭据、可选根路径）或作为**自定义服务器**（命令、参数或 URL）。只使用你信任的未知命令。探测检查是否可达；没有 Node/Docker/`uvx` 时显示「缺少运行时」。

Office 捆绑 PDF 和 Office 格式；仅在确实需要时再启用单项预设。

删除会移除服务器配置，不会移除 Ollama 或凭据。

## 数据

显示**数据文件夹**和存储状态：设置、帮助、工作区、历史 — 没有 SQL 视图，没有密钥。

仅当没有网络正在启动、运行或停止时才能**更换**文件夹。驱动器或系统根目录无效。可选将内容复制到新文件夹；旧文件夹保留。

**便携**或外部指定的文件夹：路径**只读**。

**历史保留：** 30 / 90 / 365 天或不限（默认 90）。历史页可按此清理旧条目。

## 关于

UI 与 API 版本、大致的 Ollama 状态、存储是否可达。没有密钥，也不会在你会分享的界面上显示带用户名的内部路径。
