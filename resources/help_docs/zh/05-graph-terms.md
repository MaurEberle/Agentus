# 术语

帮助聊天和编辑器的简短词汇表。

## 图 / 网络

由节点和边组成的已保存文档。在编辑器中编辑，在资料库中管理副本。**活动**网络是快速选择中的那个 — 只有它会随**启动**运行。

## 运行（run）

活动图的一次执行。最多同时**一个**。标题栏启动和停止。结果：运行中、成功、失败、已取消、超时。

## 节点与边

构件（聊天输入、智能体、LLM、工具、知识、路由器、结束）和带类型的连接。框之间的任意箭头无效。

## 智能体

带系统提示的节点。模型、消息、工具和知识通过端口进入，不是内嵌密钥。

## LLM 节点

选择提供方和模型。本地走 Ollama，否则云或 OpenAI 兼容 URL 加凭据。

## 聊天输入

运行中用户文本的唯一入口。每个网络最多一个。监控聊天写入此处。

## 工具

第一方（HTTP、网页搜索、日期/时间、计算器）或 MCP。在检查器中配置，仅在运行中执行。

## 知识（网络）

知识节点：位于应用**数据文件夹之下**的文件夹。自有索引、topK 和分数。**不是**帮助语料。不是驱动器根。

## 帮助 RAG

数据文件夹中帮助文件夹里的文档（默认指南加上你的 Markdown）。仅供帮助聊天机器人。更改后在设置 → 帮助聊天中重建索引。

## 凭据

存在 Windows 保管库中的密钥。列表中只有掩码。图中只有 ID/选择，从不是密钥。导出不含密码。

## MCP

Model Context Protocol：外部工具服务器。在设置中创建并启用，在图中作为 MCP 类型的工具节点连接。帮助不使用 MCP。

## 提供方

`ollama`（本地）、`xai`、`openai`、`anthropic`（Claude）、`gemini`（云，先 API 密钥再模型列表）、`openai_compat`（自有兼容 HTTP API，例如 LM Studio）。

## Ollama

本地模型的独立服务。应用是客户端。安装程序可以创建 Ollama 和两个默认小模型。关闭应用后 Ollama 继续运行。

## 仪表板、监控、历史

仪表板 = 概览与设置。监控 = 实时。历史 = 归档。不是同一页重复三次。

## 有效 / 无效

图的验证。无效可以保存，但不适合启动。只有有效网络可以设为活动。

## 快速选择

标题栏中对活动网络的选择。等同于资料库中的「设为活动」。

## 节省模式

主模型撑不住时，帮助切到备用模型。仪表板可在环境中显示。

## 便携

EXE 旁的 `portable.txt`：数据在应用旁边。已安装副本：数据在应用数据文件夹，程序另放。
