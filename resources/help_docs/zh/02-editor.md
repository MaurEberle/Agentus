# 编辑器与资料库

**网络**下的编辑器编辑**一份**图文档。**资料库**是目录：列表、导入、删除、设为活动。画布只存在于编辑器，不在资料库、监控或历史中。

## 两个位置

| 位置 | URL 含义 | 典型操作 |
|-----|----------|-------------------|
| 编辑器 | 新建或已打开的网络 | 绘制、检查器、保存、打开对话框、复制、导出打开的图 |
| 资料库 | 全部网络 | 搜索、标签、设为活动、导入/导出多个文件、删除 |

**设为活动**和**删除**属于资料库（活动也可用快速选择）。编辑器的打开对话框只打开**一个**网络，不会删除任何内容。

## 编辑器界面

顶部**功能区**：新建、保存、另存为、打开、复制、导出、验证、撤销/重做、视图（适应、网格、对齐、小地图）、前往资料库。

中间：**面板**（左）、**画布**、**检查器**（右）。在桌面上可以折叠。窄屏时是抽屉。空网络只提示把第一个节点从面板拖到画布上。连线是曲线，和监控、历史里一样。

从面板拖出节点。卡片保持紧凑；表单在检查器中。用 Shift 或套索多选。Delete 删除选择。撤销：Ctrl+Z。

当**正是这个**网络在运行时：横幅 **只读** — 先在标题栏停止。

## 节点类型

| 名称 | 类型 | 作用 |
|-------------|-----|---------|
| 聊天 | `chat_input` | 运行中的对话。**最多一个。** 输出 **消息**。有编排器时，聊天保持打开以便追问。 |
| 编排器 | `orchestrator` | 运行聊天的声音。输入 **消息** 和 **LLM**。每个智能体一个 **通道** 输出。**消息** 只连到 **结束**（或路由器）。**最多一个。** |
| LLM | `llm` | 提供方（Ollama、xAI、OpenAI、Claude、Gemini）、模型、云凭据、温度、token 上限。输出 **LLM**。 |
| 智能体 | `agent` | 系统提示。输入消息、LLM、工具、知识，以及可选的**通道**。输出消息和交接。通道只来自编排器。没有通道时，智能体沿消息运行一次。 |
| 工具 | `tool` | 第一方：HTTP、网页搜索、日期/时间、计算器、文件访问 — 或 **MCP**。输出 **工具**。 |
| 知识 | `knowledge` | 网络用的文件文件夹。输出 **知识**，只接到智能体的知识端口。 |
| 路由器 | `router` | 按条件分支消息（首行 / 命名分支）加上默认输出。 |
| 结束 | `end` | 收尾。**至少一个。** |

## 连接

只允许匹配的端口：

- 消息到消息（聊天 → 智能体或聊天 → 编排器，智能体 → 结束，智能体 → 路由器，路由器分支 → …）。编排器的消息只连到结束或路由器。
- 通道到通道（编排器 → 智能体）。每个智能体一个端口。回复在运行内部返回，不需要第二条边。
- LLM 输出接到智能体或编排器的 **LLM** — 每个智能体和编排器都需要**恰好一条**这样的边
- 工具输出接到智能体 **工具**（允许多条）
- 知识输出只接到智能体 **知识**
- 禁止循环（无环有向图）

无效拖放会被拒绝。

## 检查器

未选节点：打开网络的名称、描述、标签、统计、验证列表。

已选节点：

- **LLM：** 提供方、模型（运行时列表）、云凭据、探测、高级温度 / 最大 token。无凭据的云配置无效。
- **智能体：** 系统提示和显示名称。智能体在通道上时，检查器会说明任务来自编排器。
- **工具：** 类型。HTTP：方法和 URL，可选凭据。网页搜索：网页搜索类凭据。文件访问：根文件夹，不能是驱动器根；智能体只在其下工作，写入和删除是开关。MCP：设置中已启用的服务器；默认该服务器的全部工具。
- **知识：** 源文件夹（选文件夹）、嵌入提供方（Ollama、OpenAI 或 Gemini）和嵌入模型、topK、分数阈值、**重建索引**。文件夹可以在任何位置，但不能是驱动器根、系统根或帮助语料。云嵌入需要凭据。索引属于这个网络，不属于帮助。
- **聊天：** 占位符、起始文本、「需要输入」开关。
- **编排器：** 系统提示。模型在追问、通过该智能体通道发出的一项任务、回复和结束之间选择。智能体就是这些通道，不是第二份清单。
- **路由器：** 命名分支（名称 + 条件）和默认。

密钥**不属于**检查器文本，也不属于图导出 — 只选择凭据。

## 验证

功能区的**验证**会检查：

- 名称非空
- 最多一个聊天，最多一个编排器，至少一个结束
- 每个智能体：恰好一条 LLM 边。没有编排器时要有一条传入消息。有编排器时恰好一条通道，并且同一智能体上不能再有消息链
- LLM：已设模型；云：凭据
- 工具：类型；MCP：活动服务器，配方需要时的根路径；文件访问：不能是驱动器根的文件夹
- 知识：已设路径，不是根目录，不是帮助语料，提供方需要时要有嵌入凭据
- 无悬空边、无循环、端口类型匹配

有效/无效显示为徽章。无效网络可以保存，但很难启动。

## 保存、打开、导出

- **保存**（Ctrl+S）：第一次弹出名称对话框，之后更新。URL 变为 `/network/…`。
- **另存为：** 新文档，成为当前打开的。
- **打开：** 一个已保存网络；搜索和排序。批量与删除只在资料库。
- **复制：** 仅已保存的文档；打开副本。
- **导出：** 下载打开的图。包含 `credentialId`，不含密钥。资料库导入会丢弃随附的密钥。

未保存离开：保存 / 放弃 / 取消对话框。

## 资料库

带搜索（名称、描述、标签）、排序、筛选「仅有效」/「仅活动」的列表。可多选。

操作：新建（编辑器）、打开、复制、重命名、设标签、**设为活动**（仅一个有效网络）、删除、导入、导出。

删除会移除工作区条目，不会删除磁盘上的知识源文件、帮助语料或历史运行。**正在运行**的网络会被跳过。删除活动网络会清空快速选择。

导入：名称冲突的文件可重命名或跳过。不支持的架构版本会被拒绝。
