# Agentus Network — 快速入门

Agentus Network 是一款**本地桌面应用**。你在这台电脑上用智能体、语言模型和工具搭建网络，启动**一次**运行并实时查看。界面属于应用自身（独立窗口），不是 Chrome，也不是 `file://` 页面。

Ollama 是**单独的服务**。关闭或卸载 Agentus Network 不会停止 Ollama，也不会删除模型。如果这台电脑已安装 Ollama，设置里的地址是本机，而服务没在运行，应用会在打开窗口时启动它。

## 窗口与导航

左侧（手机上为汉堡菜单）：

- **仪表板** — 首页、设置、活动网络、最近运行
- **网络** — 编辑器（一张图）
- **资料库** — 所有已保存的网络
- **监控** — 实时运行
- **历史** — 已完成的运行与统计

**设置**在标题栏（齿轮），不在左侧导航。

标题栏还有：**启动** / **停止**、活动网络的**快速选择**、铃铛（通知）、浅色/深色/系统、语言（Deutsch, English, Español, Français, Türkçe, Português, 中文, 日本語, العربية）以及窗口按钮（最小化、最大化、关闭）。

拖动徽标或空白标题栏可移动窗口。启动、停止、快速选择和右侧按钮不是拖动区域。

## 第一次走通

1. Ollama 必须能连上。已安装但没在运行时，应用会自己启动本地服务。安装程序可以安装 Ollama，在后台短暂启动它，并在它有响应时拉取小模型 `nomic-embed-text` 和 `llama3.2:1b`。不带模型开关的静默安装不会下载模型。下载失败时安装仍会成功结束。
2. 在**设置 → 运行时**检查连接；模型列表不能为空。
3. 在**设置 → 帮助聊天**设置提供方和聊天模型（默认：Ollama + `llama3.2:1b`）。嵌入是**另一个**模型（`nomic-embed-text`）。
4. 在**资料库**或编辑器中创建网络、保存，并在快速选择中**设为活动**。
5. 标题栏点**启动**。运行在**监控**中查看。

仪表板会把缺失步骤显示为设置卡片。

## 最小网络

在编辑器（**网络**）中至少需要：

1. **聊天**（`chat_input`）— 最多一个
2. **智能体** — 系统提示
3. **LLM** — 提供方和模型
4. **结束**（`end`）— 至少一个

连接（带类型的端口，不是任意箭头）：

- 聊天 **消息** → 智能体 **消息**
- LLM **LLM** → 智能体 **LLM**
- 智能体 **消息** → 结束

可选**编排器**：聊天只连编排器，一个 LLM 连编排器，编排器到每个智能体的通道各一条**通道**，编排器的**消息**连到**结束**。它是运行聊天里唯一的声音，会追问，并一次只调用一个智能体。智能体正文和内部指令不会显示成聊天气泡。应用会把上一次智能体结果附到下一个任务上，不必把它贴进聊天。聊天保持打开，直到它结束这次运行。没有编排器时，每个智能体仍是自己的消息和交接链。一个智能体要么在通道上，要么在链上，不能两者都是。

可选：**工具**接到智能体或编排器的**工具**端口，**知识**接到**知识**。保存。若快速选择尚未激活，在**资料库**中「设为活动」。

## 启动与停止

**启动**会启动**活动**网络（快速选择）的**一次**运行。绝不会并行跑第二个网络。在**停止**之前，第二次启动会被拒绝。

**停止**取消运行（结果为**已取消**，不是**错误**）。Ollama 继续运行。

没有活动网络则无法启动。无效网络（验证错误、缺少模型）应先在编辑器中检查再启动。

活动网络运行时，编辑器中的**该**文档为只读。你仍可查看其他网络；资料库中无法删除正在运行的网络。

关闭窗口会结束运行和应用。Ollama 继续存活。

## 帮助聊天不是网络聊天

右下角：气泡 = **应用帮助**（本指南、图术语、可选网页搜索）。首次打开时引导会说明。

在**监控**中，**聊天**标签 = 图的**运行聊天**（聊天节点）。没有编排器时，这是给智能体的输入。有编排器时，这是对话：它可以先问你，再调用智能体。

两者不共享**历史**、工具或凭据。帮助**不**使用 MCP 服务器。

## Ollama 与云

- **本地：** Ollama，在设置中作为运行时。在那里列出并测试模型。应用在运行时**不会**静默拉取模型。
- **云：** 凭据在**设置 → 凭据**（xAI、OpenAI、Claude、Gemini、网页搜索等）。在 LLM 节点上选择 Ollama、xAI、OpenAI、Claude 或 Gemini。没有匹配凭据的云配置无效。列表只显示**掩码**，从不显示密钥。LLM 节点和帮助通过名称引用凭据，而不是把密钥写进图。

运行时不再提供 OpenAI 兼容基础 URL。已有的这类凭据仍留在凭据里。

## 单实例

第二次启动会把已有窗口提到前面。不会启动第二个后端或第二次运行。

## 便携版与已安装版

已安装的应用把数据放在本地 **Agentus-Network** 文件夹，不在程序旁边。便携版（EXE 旁的 `portable.txt`）把数据放在 **EXE 旁边**。便携模式下需自行提供 WebView2 和 Ollama。
