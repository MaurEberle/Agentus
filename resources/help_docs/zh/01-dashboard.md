# 仪表板

首页。汇总设置、活动网络和最近运行。它**不是**实时监控，也**不是**归档——那些有独立页面。

## 设置

若第一次运行还缺东西，会显示**设置**卡片，例如：

- 无法访问 Ollama → 链接 **检查运行时**
- 帮助配置没有提供方或模型 → **配置帮助**
- 还没有网络 → **新建网络**或**导入网络**

环境齐全时卡片会消失。静默安装未拉取的可选模型不会变成第二个向导：运行时探测或帮助聊天会显示错误。

## 主机资源

与**监控**相同的卡片：CPU、内存和 **本机** GPU/显存，不只是应用进程。即使没有活动运行，数值也会持续更新。

## 状态

显示服务是**已停止**、**正在启动**、**运行中**还是**正在停止**，以及活动网络。网络运行时：链接 **监控**，可选「已运行 …」。没有快速选择：提示并链接到**资料库**。

启动和停止仍在**标题栏**，不在这张卡片上。

## 活动网络

名称、节点/边数量、有效/无效、上次更改。操作：**编辑**（编辑器）、**资料库**、**新建网络**。

无效表示编辑器验证失败（例如某个 LLM 节点缺少模型）。这类网络不应启动。

## 最近使用

按最近使用排列的已保存网络短列表。点击打开编辑器。空：还没有网络。

## 最近运行

历史中的最新条目（成功、失败、已取消、超时，或仍在运行）。正在运行的条目进入**监控**，已结束的进入**历史**。若历史存储损坏，会提示并链接到**数据**。

## 最近 7 天

小统计：运行次数、成功、失败。链接 **历史** 可筛选和看图表。这是摘要，不是第二份归档。

## 环境

- Ollama 是否可达，大致模型数量
- 存储问题（设置、帮助、工作区、历史）
- 帮助已切到备用模型时的**节省模式**

链接：**数据**、运行时。

## 快捷方式

**新建网络**、**导入**（资料库）、**运行时**。导航和设置中也有相同操作。
