# 設定

ヘッダーの歯車。左の区画: 外観、資格情報、ランタイム、ヘルプチャット、MCP サーバー、データ、情報。区画を離れるときの未保存: 残る / 破棄。

## 外観

ライト、ダーク、またはシステム — ヘッダーを含むアプリ全体。**言語**は旗付きドロップダウンです: Deutsch, English, Español, Français, Türkçe, Português, 中文, 日本語, العربية。括弧内は現在の UI 言語での訳です。

**ヘルプボタン**スイッチ: 右下の吹き出しの表示/非表示。吹き出しを隠してもチャットボットの**設定**は **ヘルプチャット** に残ります。

## 資格情報

クラウドモデル、ウェブ検索、一部の MCP レシピ用の名前付き秘密。作成: 名前、種類、秘密を**一度**。以降は **マスク** のみ。編集は秘密を差し替えられます（空 = 変更なし）。

種類の例: xAI、OpenAI 互換、ウェブ検索、GitHub、Azure、GitLab、Slack、Notion、Atlassian、Linear、Postgres、トークン。

ヘルプ設定、ネットワーク（LLM/ツール）、または MCP サーバーが使っている間は **削除** できません。先に割り当てを外します。

## ランタイム

**Ollama ベース URL**（多くの場合 Ollama のローカルアドレス）と任意の **OpenAI 互換ベース URL**。**接続の確認**と**モデル一覧**はアプリ経由で、ブラウザ直ではありません。

Ollama に届かないとローカル LLM ノードと既定ヘルプは止まります。モデルは Ollama かセットアップで入れます。アプリは実行時に黙って **pull しません**。

## ヘルプチャット

ヘルプウィジェットの唯一の場所。チャットプロバイダーとモデルがなければ未完了です。

- チャットプロバイダーとモデル（既定 Ollama / `llama3.2:1b`）
- 任意のクラウド資格情報
- **埋め込みプロバイダーとモデル**（既定 Ollama / `nomic-embed-text`）— チャットモデルでは**ありません**
- 任意の節約モデル（フォールバック、既定は同じ小さいチャット）
- ウェブ検索のオン/オフと検索資格情報。資格情報がなくてもチャットは設定済み、検索はオフ
- 接続確認、履歴消去、**インデックス再構築**、オンボーディング再表示

埋め込みモデル変更後やヘルプコーパスへの新ファイル後: **インデックス再構築**。コーパスはデータフォルダー内のヘルプ文書フォルダーであり、ネットワーク知識ではありません。

ヘルプは MCP サーバーもグラフの knowledge も**使いません**。

## MCP サーバー

外部ツールのひな型（**レシピ**）: GitHub、ファイルシステム、Git、Playwright、Postgres、Slack、Notion、Office 形式など。レシピは同梱プログラムではありません。多くは PC 上の Node/`npx`、Docker、`uvx` と資格情報が必要です。

既定: サーバー **無効**。アプリは起動時に MCP プロセスを始めず、実行が接続済み MCP ツールノードを必要としたときに始めます。

レシピから作成（資格情報、任意のルートパス）するか **独自サーバー**（コマンド、引数、URL）。未知のコマンドは信頼できるものだけ。プローブは到達を確認。Node/Docker/`uvx` がなければ「ランタイムなし」。

Office は PDF と Office 形式をまとめます。個別プリセットは本当に必要なときだけ。

削除はサーバー設定を外し、Ollama も資格情報も消しません。

## データ

**データフォルダー**とストア状態: 設定、ヘルプ、ワークスペース、履歴 — SQL ビューも秘密もなし。

フォルダー**変更**は、ネットワークが開始・実行・停止していないときだけ。ドライブやシステムのルートは不可。任意で内容を新しいフォルダーへコピー。古いフォルダーは残ります。

**ポータブル**または外部指定フォルダー: パスは **読み取り専用**。

**履歴の保持:** 30 / 90 / 365 日または無制限（既定 90）。履歴ページは古い項目をそれに合わせて掃除できます。

## 情報

UI と API のバージョン、おおよその Ollama 状態、ストアが届くか。秘密なし。共有する画面にユーザー名入りの内部パスは出しません。
