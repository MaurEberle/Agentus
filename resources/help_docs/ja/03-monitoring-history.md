# 監視と履歴

**監視** = いま、1つの実行。**履歴** = アーカイブと統計。履歴は**第二のダッシュボード**でも**ライブログ**でもありません。開始と停止は **ヘッダー** のままです。

## ライブ対アーカイブ

| | 監視 | 履歴 |
|---|------------|----------|
| いつ | サービスが開始・実行・停止 | 実行終了後（実行中はリンク） |
| グラフ | ミニグラフ、読み取り専用、ノード状態 | 保存スナップショット、ライブ更新なし |
| ログ | 流れ、最新が上、一時停止可 | 固定行、フィルタ可 |
| チャット | 実行チャット、実行中のみ | 保存された転写、追記不可 |

まだ実行中の履歴項目は監視へのジャンプだけです（「ライブで見る」）。

## 実行なしの監視

実行中がなければ、ページは**最後に保存した実行**を閲覧用に出します（グラフ、アクティビティ、ログ、チャット）。ライブではない旨の案内があります。保存済みの実行が一度もないときだけ、ページは空です。**実行なし**に加え、アクティブなネットワークか、クイック選択が空である旨。切断 / エラー / 開始中 / 停止中はそれぞれの文。知識の索引中は、開始の案内がそのノード名に替わります。接続まで直近の値は薄くなります。

## 実行中

ヘッダー: 実行 ID、開始時刻、所要時間、おおよそのステップ、アクティブな LLM（ローカル対クラウド）。

**ネットワーク（読み取り専用）:** 同じグラフ。状態でノード色（アイドル、待機、実行中、完了、エラー）。ノードをクリックするとログ/アクティビティを絞り、詳細（役割、状態、LLM/ツール/入力/索引待ち、最後のメッセージ、トークン）を開きます。編集なし、第二エディターなし。

エージェントに知識が付いていると、索引のあいだも開始時点で実行が見えます。知識ノードは待ち理由 **索引** で動き、ログは読み取りと埋め込みを書き、ヘッダーとダッシュボードは同じ名前を出します。すでに最新の索引は飛ばされ、最新とだけ記されます。

**アクティビティ:** 現在のノード、「ステップ x / y」、入出力トークン、任意のコンテキスト窓。

**ホストリソース:** **この PC** の CPU、RAM、GPU/VRAM。アプリだけではありません。ローカル GPU なし（クラウド実行でよくある）は案内でありエラーではありません。

## ネットワークチャット（監視）

**チャット**タブ: 実行中グラフの会話。実行中のみ有効。オーケストレーターがなければ、チャットは最初の行を待って連鎖へ渡します。あれば、話す相手はそれだけです。確認の質問は同じ実行の中で開いたままです。エージェントの本文と内部の指示はここには出ません。

これはヘルプ吹き出しでは**ありません**。履歴とツールはネットワーク側です。

## ログ（監視）

**ログ**タブ: レベル（デバッグ、情報、警告、エラー）、ノード、時刻。最新が上。一時停止で追従を止め、「最新へ」で再び末尾へ。フィルタ: 検索、レベル以上、特定ノード、エラーのみ。見える行をエクスポート。

ペイロードとメッセージは秘密を**マスク**します（例: `Bearer`、キー接頭辞）。未フィルタで渡さないでください。

## 履歴

リボン: 更新、選択した実行の削除、ログのエクスポート、保持に応じた古い項目の掃除（設定 → データ、既定 90 日）。

**1つのフィルタ**が全体を動かします: 期間（今日、7/30 日、開始–終了）、ネットワーク、モデル、検索（実行 ID、ネットワーク、エラー）。KPI、「日ごとの実行」グラフ、多いエラー、履歴 / モデル別 / ネットワーク別タブと一覧が同じフィルタです。

## 実行の結果

| 結果 | 意味 |
|----------|-----------|
| 実行中 | まだアクティブ — 履歴ではリンクのみ |
| 成功 | 正常終了 |
| 失敗 | ステップまたはサービス失敗 |
| キャンセル | ヘッダーの停止、ウィンドウ閉じ、またはアプリ終了（クラッシュ後の次回起動も含む） |
| タイムアウト | 時間超過 |

**キャンセルはエラーではありません。** タイムアウトとキャンセルは KPI で別カウント（「失敗」の脚注）。

## 実行の詳細

右側または専用ビュー: メタ、ミニグラフ、**ログ**、**ステップ**、**チャット**タブ。ステップ: ノード、役割、状態、エラー。チャット: 転写、読み取り専用。単一ログのエクスポート。

履歴項目の削除は保存済みネットワークを変えません。
