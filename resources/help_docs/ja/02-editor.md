# エディターとライブラリ

**ネットワーク**のエディターはグラフ文書を**1つ**編集します。**ライブラリ**はカタログです: 一覧、インポート、削除、アクティブ化。キャンバスはエディターだけにあり、ライブラリ・監視・履歴にはありません。

## 2つの場所

| 場所 | URL の意味 | 典型操作 |
|-----|----------|-------------------|
| エディター | 新規または読み込んだネットワーク | 描画、インスペクター、保存、開くダイアログ、複製、開いているグラフのエクスポート |
| ライブラリ | すべてのネットワーク | 検索、タグ、アクティブにする、複数ファイルのインポート/エクスポート、削除 |

**アクティブにする**と**削除**はライブラリ側です（アクティブはクイック選択でも可）。エディターの開くダイアログはネットワークを**1つ**開くだけで、何も消しません。

## エディター画面

上の **リボン**: 新規、保存、名前を付けて保存、開く、複製、エクスポート、検証、元に戻す/やり直す、表示（合わせる、グリッド、スナップ、ミニマップ）、ライブラリへ。

中央: **パレット**（左）、**キャンバス**、**インスペクター**（右）。デスクトップでは折りたためます。狭い画面では引き出しです。空のネットワークは、最初のノードをパレットからキャンバスへドラッグする案内だけです。線は曲線で、監視と履歴と同じです。

ノードはパレットからドラッグ。カードはコンパクトのまま、フォームはインスペクター。Shift またはラッソで複数選択。Delete で選択削除。元に戻す: Ctrl+Z。

**まさにこの**ネットワークの実行中: バナー **読み取り専用** — まずヘッダーで停止。

## ノードの種類

| 表示名 | 型 | 役割 |
|-------------|-----|---------|
| チャット | `chat_input` | 実行中の会話。**最大1つ。** 出力 **メッセージ**。オーケストレーターがあると、質問のために開いたままです。 |
| オーケストレーター | `orchestrator` | 実行チャットの声。入力は **メッセージ**、**LLM**、**ツール**。エージェントごとに **チャネル** 出力。**メッセージ** は **終了** かルーターへだけ。**最大1つ。** |
| LLM | `llm` | プロバイダー（Ollama、xAI、OpenAI、Claude、Gemini）、モデル、クラウド資格情報、温度、トークン上限。出力 **LLM**。 |
| エージェント | `agent` | システムプロンプト。入力はメッセージ、LLM、ツール、知識、任意の**チャネル**。出力はメッセージと引き継ぎ。チャネルはオーケストレーターからだけ。なければメッセージで一度だけ動く。 |
| ツール | `tool` | ファーストパーティ: HTTP、ウェブ検索、日付/時刻、電卓、ファイルアクセス。出力 **ツール**。 |
| MCP | `mcp` | **設定**で作成し**有効化**したサーバー。出力 **ツール**（ツールノードと同じ）。 |
| 知識 | `knowledge` | ネットワーク用のファイルフォルダー。出力 **知識**。エージェントの知識ポートのみ。 |
| ルーター | `router` | 条件でメッセージを分岐（先頭行 / 名前付き枝）と既定出力。 |
| 終了 | `end` | 締め。**少なくとも1つ。** |

## 接続

互換ポートのみ:

- メッセージからメッセージ（チャット → エージェントまたはチャット → オーケストレーター、エージェント → 終了、エージェント → ルーター、ルーター枝 → …）。オーケストレーターのメッセージは終了かルーターへだけ。
- チャネルからチャネル（オーケストレーター → エージェント）。エージェントごとに1ポート。返事は実行の中で戻り、2本目の線は要りません。
- LLM 出力はエージェントまたはオーケストレーターの **LLM** — それぞれ**ちょうど1本**
- ツール出力はエージェントまたはオーケストレーターの **ツール**（複数可）。一つのツールは両方へつながる。
- 知識出力はエージェントの **知識** のみ
- 循環は禁止（ループのない有向グラフ）

無効なドラッグは拒否されます。

## インスペクター

ノード未選択: **開いている**ネットワークの名前、説明、タグ、統計、検証リスト。タグはチップです。Enter、カンマ、または + で確定し、× で削除します。管理画面は同じタグで絞り込みます。

ノード選択時:

- **LLM:** プロバイダー、モデル（ランタイムの一覧）、クラウド資格情報、モデル上限に応じたコンテキスト長（ローカルはスライダー、クラウドは一覧）、ノードごとの CPU スレッド（既定は物理コア）、ノードごとの GPU オフロードはレイヤー単位（既定は全レイヤー、読み込み失敗時は Auto）、コンテキストとオフロードから見た GPU メモリ見積もり（GPU は末尾の N 層；フルアテンションはコンテキスト全体、スライディングウィンドウ層はその窓だけ；カードに収まらなければ警告）、ping、詳細の温度 / 最大トークン。資格情報なしのクラウドは無効。
- **エージェント:** システムプロンプトと表示名。チャネル上なら、依頼はオーケストレーターから来る旨をインスペクターが説明します。結果を書く前やツールを呼ぶ前に内部で思考できます。思考はチャットに出ません。
- **ツール:** 種類。HTTP: メソッドと URL、任意の資格情報。ウェブ検索: ウェブ検索種別の資格情報。ファイルアクセス: ルートフォルダー。ドライブルートは不可。エージェントはその下だけで動き、書き込みと削除はスイッチです。
- **MCP:** **設定 → MCPサーバー** の有効なサーバー。既定は全ツール。確認後に一部だけ選べます。資格情報は設定側。ファイルシステムと Excel のルートはノード、Git のフォルダーは設定です。
- **知識:** ソースフォルダー（フォルダー選択）、埋め込みプロバイダー（Ollama、OpenAI、Gemini）と埋め込みモデル、topK、スコアしきい値、**インデックス再構築**。フォルダーはドライブ根、システム根、ヘルプコーパス以外ならどこでも置けます。Markdown、テキスト、PDF、Word（.docx）、Excel（.xlsx）、HTML、JSON、CSV、ソースコードを索引します。画像と古い .doc/.xls は対象外です。クラウド埋め込みには資格情報が要ります。索引はこのネットワークのもので、ヘルプのものではありません。
- **チャット:** プレースホルダー、開始テキスト、「入力必須」スイッチ。
- **オーケストレーター:** システムプロンプト。モデルは思考、確認の質問、そのエージェントのチャネルへの1件の依頼、返答、終了のどれかを選びます。思考はチャットに出ず、ステップ上限にも数えません。数えるのはエージェント呼び出しだけです。エージェントはチャネルであり、別リストではありません。つながったツールは自分で呼びます。待つのは確認の質問のときだけです。
- **ルーター:** 名前付き枝（名前 + 条件）と既定。

秘密はインスペクター文にもグラフエクスポートにも**入れません** — 資格情報の選択だけです。

## 検証

リボンの **検証** は次などを見ます:

- 名前が空でない
- チャットは最大1、オーケストレーターは最大1、終了は少なくとも1
- 各エージェント: LLM エッジちょうど1本。オーケストレーターがなければ着信メッセージが1つ。あればチャネルがちょうど1つで、同じエージェントにメッセージ連鎖はない
- LLM: モデル設定済み。クラウド: 資格情報
- ツール: 種類。MCP: 有効なサーバー、レシピが要るならルートパス。ファイルアクセス: ドライブルートではないフォルダー
- 知識: パスあり、根ではない、ヘルプコーパスではない、プロバイダーが要るなら埋め込みの資格情報
- ぶら下がりエッジなし、循環なし、ポート型が合う

有効/無効はバッジです。無効なネットワークは保存できますが、開始には向きません。

## 保存、開く、エクスポート

- **保存**（Ctrl+S）: 初回は名前ダイアログ、以降は更新。URL は `/network/…` になります。
- **名前を付けて保存:** 新しい文書が開いているものになります。
- **開く:** 保存済みを1つ。検索と並べ替え。一括と削除はライブラリのみ。
- **複製:** すでに保存済みの文書のみ。コピーを開きます。
- **エクスポート:** 開いているグラフのダウンロード。`credentialId` を含み、キーは含みません。ライブラリのインポートは付いてきた秘密を捨てます。

未保存で離れる: 保存 / 破棄 / キャンセル。

## ライブラリ

検索（名前、説明、タグ）、並べ替え、「有効のみ」/「アクティブのみ」フィルタ。複数選択。

操作: 新規（エディター）、開く、複製、名前の変更、タグ、**アクティブにする**（有効なネットワーク1つのみ）、削除、インポート、エクスポート。タグ設定は選択中の既存タグをチップとして開きます。

削除はワークスペース項目を外します。ディスク上の知識ソース、ヘルプコーパス、履歴の実行は残します。**実行中**のネットワークはスキップされます。アクティブなネットワークを消すとクイック選択が空になります。

インポート: 名前衝突は改名かスキップ。非対応の schema バージョンは拒否されます。
