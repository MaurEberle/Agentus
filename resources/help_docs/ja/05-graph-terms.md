# 用語

ヘルプチャットとエディター向けの短い用語集です。

## グラフ / ネットワーク

ノードとエッジの保存文書。エディターで編集し、ライブラリでコピーを管理します。**アクティブ**なネットワークはクイック選択のもの — **開始**はその1つだけです。

## 実行（run）

アクティブなグラフの1回の実行。同時に動くのは**最大1つ**。開始と停止はヘッダー。結果: 実行中、成功、失敗、キャンセル、タイムアウト。

## ノードとエッジ

部品（チャット入力、エージェント、LLM、ツール、知識、ルーター、終了）と型付き接続。箱の間の任意の矢印は無効です。

## エージェント

システムプロンプト付きノード。モデル、メッセージ、ツール、知識はポートから入り、埋め込みキーではありません。

## LLM ノード

プロバイダーとモデルを選びます。ローカルは Ollama、それ以外はクラウドか OpenAI 互換 URL と資格情報。

## チャット入力

実行中のユーザーテキストの唯一の入口。ネットワークあたり最大1つ。監視チャットはここに書きます。

## ツール

ファーストパーティ（HTTP、ウェブ検索、日付/時刻、電卓）または MCP。設定はインスペクター、実行はラン中のみ。

## 知識（ネットワーク）

knowledge ノード: アプリの**データフォルダーの下**のフォルダー。独自インデックス、topK、スコア。**ヘルプコーパスではない**。ドライブルートでもない。

## ヘルプ RAG

データフォルダー内のヘルプフォルダーの文書（既定ガイドと自分の Markdown）。ヘルプチャットボット専用。変更後は設定 → ヘルプチャットでインデックス再構築。

## 資格情報

Windows 保管庫のキー。一覧はマスクのみ。グラフでは ID/選択のみで秘密は出ません。エクスポートにパスワードはありません。

## MCP

Model Context Protocol: 外部ツールサーバー。設定で作成・有効化し、グラフでは MCP 種のツールノードとしてつなぎます。ヘルプは MCP を使いません。

## プロバイダー

`ollama`（ローカル）、`xai`、`openai`、`anthropic`（Claude）、`gemini`（クラウド、先に API キー、その後モデル一覧）、`openai_compat`（自前の互換 HTTP API、例: LM Studio）。

## Ollama

ローカルモデル用の別サービス。アプリはクライアント。セットアップは Ollama と 2 つの小さい既定モデルを作れます。アプリを閉じても Ollama は動きます。

## ダッシュボード、監視、履歴

ダッシュボード = 概要とセットアップ。監視 = ライブ。履歴 = アーカイブ。同じページの三重ではありません。

## 有効 / 無効

グラフの検証。無効でも保存できますが開始向きではありません。有効なネットワークだけをアクティブにできます。

## クイック選択

ヘッダーでのアクティブネットワーク選択。ライブラリの「アクティブにする」と同じです。

## 節約モード

主モデルが持たないとき、ヘルプがフォールバックに落ちます。ダッシュボードは環境に出せます。

## ポータブル

EXE 隣の `portable.txt`: データはアプリの隣。インストール版: データはアプリのデータフォルダー、プログラムは別。
