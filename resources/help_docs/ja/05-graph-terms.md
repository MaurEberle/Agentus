# 用語

ヘルプチャットとエディター向けの短い用語集です。

## グラフ / ネットワーク

ノードとエッジの保存文書。エディターで編集し、ライブラリでコピーを管理します。**アクティブ**なネットワークはクイック選択のもの — **開始**はその1つだけです。

## 実行（run）

アクティブなグラフの1回の実行。同時に動くのは**最大1つ**。開始と停止はヘッダー。結果: 実行中、成功、失敗、キャンセル、タイムアウト。

## ノードとエッジ

部品（チャット、オーケストレーター、エージェント、LLM、ツール、知識、ルーター、終了）と型付き接続。箱の間の任意の矢印は無効です。

## エージェント

システムプロンプト付きノード。モデル、メッセージ、ツール、知識はポートから入ります。オーケストレーターがなければメッセージが起動し、メッセージか引き継ぎが答えを渡します。あれば自分のチャネルに付きます。依頼が1つ入り、結果が1つ戻ります。

## LLM ノード

プロバイダーとモデルを選びます。ローカルは Ollama、それ以外はクラウドと資格情報です。

## チャット

実行中のユーザーテキストの唯一の入口。ネットワークあたり最大1つ。監視チャットはここに書きます。オーケストレーターがあると、会話は複数のメッセージにわたって開いたままです。

## オーケストレーター

自分の LLM を持つノード。実行チャットの唯一の声で、確認の質問をし、つながったエージェントを一度に1つ、それぞれチャネルで呼びます。最大1つ。チャットはこれだけにつながります。メッセージ出力は終了かルーターへ。エージェントの本文と内部の指示は吹き出しになりません。アプリは最新の結果を次の依頼に付けます。エージェントはチャネルかメッセージ連鎖のどちらかです。ツールはツール端子につなげられ、自分で呼びます。

## ツール

ファーストパーティ（HTTP、ウェブ検索、日付/時刻、電卓、ファイルアクセス）または MCP。ファイルアクセスはルートフォルダーの中に留まり、ドライブルートではありません。設定はインスペクター、実行はラン中のみ。

## 知識（ネットワーク）

知識ノード: ネットワーク用のテキストフォルダー。ドライブ根、システム根、ヘルプコーパス以外ならどこにでも置けます。独自の埋め込みモデル、索引、topK、スコア。**ヘルプコーパスではない**。開始時に索引が見え、すでに最新なら飛ばされます。

## ヘルプ RAG

データフォルダー内のヘルプフォルダーの文書（既定ガイドと自分の Markdown）。ヘルプチャットボット専用。変更後は設定 → ヘルプチャットでインデックス再構築。

## 資格情報

Windows 保管庫のキー。一覧はマスクのみ。グラフでは ID/選択のみで秘密は出ません。エクスポートにパスワードはありません。

## MCP

Model Context Protocol: 外部ツールサーバー。設定で作成・有効化し、グラフでは MCP 種のツールノードとしてつなぎます。ヘルプは MCP を使いません。

## プロバイダー

一覧では `ollama`（ローカル）、`xai`、`openai`、`anthropic`（Claude）、`gemini`（クラウドは先に資格情報、その後モデル一覧）。埋め込みは Ollama、OpenAI、Gemini。`openai_compat` は古いグラフと資格情報では有効ですが、モデル一覧にはもうありません。

## Ollama

ローカルモデル用の別サービス。アプリはクライアント。インストール済みでアドレスがローカル、ポートが応答しないときは、アプリが起動し、止めません。セットアップは Ollama を入れ、少し待ち、応答すれば2つの小さい既定モデルを取得できます。

## ダッシュボード、監視、履歴

ダッシュボード = 概要とセットアップ。監視 = ライブ。履歴 = アーカイブ。同じページの三重ではありません。

## 有効 / 無効

グラフの検証。無効でも保存できますが開始向きではありません。有効なネットワークだけをアクティブにできます。

## クイック選択

ヘッダーでのアクティブネットワーク選択。ライブラリの「アクティブにする」と同じです。

## 節約モード

主モデルが持たないとき、ヘルプがフォールバックに落ちます。ダッシュボードは環境に出せます。

## ポータブル

EXE 隣の `portable.txt`: データはアプリの隣。インストール版: データはアプリのデータフォルダー、プログラムは別。
