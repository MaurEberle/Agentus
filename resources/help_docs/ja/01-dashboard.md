# ダッシュボード

スタートページです。セットアップ、アクティブなネットワーク、最近の実行をまとめます。**ライブ監視**でも**アーカイブ**でもありません。それらは別ページです。

## セットアップ

初回実行に何か足りないとき **セットアップ** カードが出ます。例:

- Ollama に届かない → **ランタイムを確認** リンク
- ヘルプ設定にプロバイダーまたはモデルがない → **ヘルプを設定**
- まだネットワークがない → **新しいネットワーク** または **ネットワークをインポート**

環境が揃うとカードは消えます。サイレントセットアップで取られなかった任意モデルは第二のウィザードではありません。ランタイムの ping かヘルプチャットがエラーを出します。

## ホストリソース

**監視**と同じカード: CPU、メモリ、**この PC** の GPU/VRAM。アプリプロセスだけではありません。実行がなくても値は継続して更新されます。

## 状態

サービスが **停止**、**開始中**、**実行中**、**停止処理中** かと、アクティブなネットワークを示します。実行中のネットワークでは **監視** リンクと任意で「…から実行中」。クイック選択が空なら案内と **ライブラリ** リンク。

開始と停止は **ヘッダー** のまま、このカードにはありません。

## アクティブなネットワーク

名前、ノード/エッジ数、有効/無効、最終更新。操作: **編集**（エディター）、**ライブラリ**、**新しいネットワーク**。

無効はエディターの検証失敗です（例: LLM ノードにモデルがない）。そうしたネットワークは開始しないでください。

## 最近使用

最終使用順の短い保存済みリスト。クリックでエディターを開きます。空: まだネットワークがありません。

## 最近の実行

履歴の最新エントリ（成功、失敗、キャンセル、タイムアウト、またはまだ実行中）。実行中は **監視**、終了済みは **履歴** へ。履歴ストアが壊れていると **データ** リンク付きの案内が出ます。

## 直近 7 日

小さな統計: 実行数、成功、失敗。フィルタとグラフは **履歴** リンク。要約であり、第二のアーカイブではありません。

## 環境

- Ollama に届くか、おおよそのモデル数
- ストアの問題（設定、ヘルプ、ワークスペース、履歴）
- ヘルプがフォールバックモデルに落ちたときの **節約モード**

リンク: **データ**、ランタイム。

## クイックリンク

**新しいネットワーク**、**インポート**（ライブラリ）、**ランタイム**。同じ操作はナビと設定からもできます。
