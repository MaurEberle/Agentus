# Agentus Network — クイックスタート

Agentus Network は**ローカルのデスクトップアプリ**です。この PC 上でエージェント、言語モデル、ツールのネットワークを組み立て、**1つ**の実行を開始してライブで見ます。UI はアプリ自身のウィンドウであり、Chrome でも `file://` ページでもありません。

Ollama は**別サービス**です。Agentus Network を閉じたりアンインストールしても Ollama は止まりませんし、モデルも消えません。この PC に Ollama があり、設定のアドレスがローカルで、サービスが止まっているときは、ウィンドウを開くとアプリが起動します。

## ウィンドウとナビ

左（電話ではバーガーメニュー）:

- **ダッシュボード** — ホーム、セットアップ、アクティブなネットワーク、最近の実行
- **ネットワーク** — エディター（1つのグラフ）
- **ライブラリ** — 保存済みネットワークすべて
- **監視** — ライブ実行
- **履歴** — 完了した実行と統計

**設定**はヘッダー（歯車）にあり、左ナビにはありません。

ヘッダーにはさらに **開始** / **停止**、アクティブネットワークの**クイック選択**、ベル（通知）、ライト/ダーク/システム、言語（Deutsch, English, Español, Français, Türkçe, Português, 中文, 日本語, العربية）、ウィンドウボタン（最小化、最大化、閉じる）があります。

ロゴまたは空のヘッダーをドラッグしてウィンドウを動かします。開始、停止、クイック選択、右側のボタンはドラッグ領域ではありません。

## 最初の流れ

1. Ollama に届くこと。インストール済みで止まっていれば、アプリがローカルサービスを自分で起動します。セットアップは Ollama を入れ、短時間バックグラウンドで起動し、応答があれば小さいモデル `nomic-embed-text` と `llama3.2:1b` を取得します。モデルスイッチのないサイレントセットアップは何も取得しません。取得に失敗してもセットアップは成功で終わります。
2. **設定 → ランタイム**で接続を確認。モデル一覧が空でないこと。
3. **設定 → ヘルプチャット**でプロバイダーとチャットモデルを設定（既定: Ollama + `llama3.2:1b`）。埋め込みは**別の**モデル（`nomic-embed-text`）です。
4. **ライブラリ**またはエディターでネットワークを作り、保存し、クイック選択で**アクティブにする**。
5. ヘッダーの **開始**。実行は **監視** で見ます。

ダッシュボードは足りない手順をセットアップカードとして出します。

## 最小のネットワーク

エディター（**ネットワーク**）で少なくとも:

1. **チャット**（`chat_input`）— 最大1つ
2. **エージェント** — システムプロンプト
3. **LLM** — プロバイダーとモデル
4. **終了**（`end`）— 少なくとも1つ

接続（型付きポート。任意の矢印ではない）:

- チャットの **メッセージ** → エージェントの **メッセージ**
- LLM の **LLM** → エージェントの **LLM**
- エージェントの **メッセージ** → 終了

任意の**オーケストレーター**: チャットはオーケストレーターだけへ、LLM を1つオーケストレーターへ、エージェントごとの**チャネル**をオーケストレーターからそのチャネルへ、**メッセージ**はオーケストレーターから**終了**へ。実行チャットの唯一の声で、確認の質問をし、エージェントを一度に1つ呼びます。エージェントの本文と内部の指示は吹き出しになりません。各エージェントは自分の本文を保持します。ツール付きのエージェントは作者の原文と、すでに書いたファイルの一覧を受け取ります。オーケストレーターが見るのは短い概要だけです。エージェントにツールがあり、呼び出さないか呼び出しが失敗した場合、その作業は未完了のままです。チャットには完了として出ません。オーケストレーターが実行を終えるまでチャットは開いたままです。オーケストレーターがなければ、各エージェントはメッセージと引き継ぎの自分の連鎖です。エージェントはチャネルか連鎖のどちらかで、両方にはなりません。

任意: **ツール**をエージェントの **ツール**ポートへ、**知識**を **知識**へ。保存。クイック選択がまだなら **ライブラリ**で「アクティブにする」。

## 開始と停止

**開始**は**アクティブ**なネットワーク（クイック選択）の実行を**1つ**始めます。2つ目のネットワークは並列に動きません。**停止**まで 2 回目の開始は拒否されます。

**停止**は実行をキャンセルします（結果は **キャンセル** であり **エラー** ではありません）。Ollama は動いたままです。

アクティブなネットワークがなければ何も始まりません。無効なネットワーク（検証エラー、モデル不足）は開始前にエディターで確認してください。

アクティブなネットワークの実行中、エディターの**その**文書は読み取り専用です。他のネットワークは引き続き見られます。ライブラリで実行中のネットワークを削除することはできません。

ウィンドウを閉じると実行とアプリが終わります。Ollama は生き続けます。

## ヘルプチャットはネットワークチャットではない

右下の吹き出し = **アプリのヘルプ**（このガイド、グラフ用語、任意のウェブ検索）。初回オープン時にオンボーディングが説明します。

**監視**の **チャット**タブ = グラフの**実行チャット**（チャットノード）。オーケストレーターがなければエージェントへの入力です。あれば会話です。エージェントを呼ぶ前に質問できます。

履歴・ツール・資格情報は**共有しません**。ヘルプは MCP サーバーを**使いません**。

## Ollama とクラウド

- **ローカル:** 設定のランタイムとしての Ollama。そこでモデルを一覧・確認します。アプリは実行時に黙ってモデルを**取り込みません**。
- **クラウド:** **設定 → 資格情報**（xAI、OpenAI、Claude、Gemini、ウェブ検索など）。LLM ノードでは Ollama、xAI、OpenAI、Claude、Gemini から選びます。合う資格情報のないクラウドは無効です。一覧は**マスク**だけを見せ、秘密は見せません。LLM ノードとヘルプはグラフにキーを書かず、名前で資格情報を指します。

OpenAI 互換のベース URL はランタイムではもう選べません。その種類の既存の資格情報は資格情報に残ります。

## 1インスタンス

2 回目の起動は既存ウィンドウを前面に出します。2 つ目のバックエンドも実行も始まりません。

## ポータブルとインストール版

インストール版はデータをローカルの **Agentus-Network** フォルダーに置き、プログラムの隣には置きません。ポータブル（EXE の隣の `portable.txt`）はデータを **EXE の隣**に置きます。ポータブルでは WebView2 と Ollama を自分で用意します。
