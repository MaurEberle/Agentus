# Terms

**Graph** — saved network of nodes and edges.

**Run** — one execution. Only one at a time.

**Credential** — secret in the vault; nodes store an ID only.

**MCP** — Model Context Protocol: external tools (GitHub, filesystem, …) as `kind: mcp` nodes.

**Help RAG** — documents in `agentus_network_rag_documents` for the help FAB.

**Network knowledge** — knowledge nodes with their own folder **under** the data directory; not the help corpus.
