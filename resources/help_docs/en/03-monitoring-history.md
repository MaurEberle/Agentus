# Monitoring and history

## Live (Monitoring)

During a run: mini-graph with status, log (newest first), resources, optional network chat. Start/stop stay in the **header**.

## Archive (History)

Finished runs, filters, stats. This is **not** a second dashboard and **not** a live tail. `cancelled` is not `failed`. A still-running row is only a link to Monitoring.

Logs and chat transcripts mask secrets (`Bearer`, `sk-…`).
